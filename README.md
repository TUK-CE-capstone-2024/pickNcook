# 🛒 픽앤쿡 Pick and Cook  
**스마트 냉장고와 쇼핑 카트를 연동한 맞춤형 레시피 추천 애플리케이션**

## 📌 프로젝트 소개  
> "식재료 확인부터 레시피 추천까지, 요리를 더 똑똑하게!"

Pick and Cook은 스마트 냉장고와 쇼핑카트의 카메라로 식재료를 인식하고,  
사용자가 보유한 재료와 요리 선호를 바탕으로 **맞춤형 레시피를 제공하는 서비스**입니다.  
중복 구매를 방지하고 식재료 활용도를 높이며 보다 효율적으로 요리할 수 있도록 돕는 것을 목표로 합니다.

## 🍽 주요 기능  

#### 1. 식재료 인식 및 중복 알림
- 냉장고: 내부 카메라로 **YOLO 기반 식재료 이미지 인식**
- 쇼핑 카트: 카메라를 통해 **바코드 인식**
- 냉장고에 이미 있는 식재료가 쇼핑 카트에 담길 경우 중복 알림 제공

#### 2. 맞춤형 레시피 추천  
- 사용자 식재료 선택 + 요리 카테고리(한식, 중식, 찌개, 디저트 등) 설정  
- GPT-4 API를 통해 **필요한 재료, 조리법, 만개의 레시피 링크 제공**

#### 3. 식재료 정보 조회  
- GPT-4 API를 통해 각 식재료의 **영양 성분**, **효능**, **보관 방법** 정보 제공  

#### 4. 선호 식재료 관리  
- 선호 식재료 등록 가능  
- 해당 재료 소진 시 알림 제공
